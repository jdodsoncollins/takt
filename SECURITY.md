# Security Policy

## Supported version

Security fixes target the current `main` branch.

## Report a vulnerability

Open a [private security advisory](https://docs.github.com/en/code-security/security-advisories/working-with-repository-security-advisories/creating-a-repository-security-advisory) on this repository. Include the affected version, reproduction steps, impact, and any proposed mitigation.

Do not file credential material, tokens, private Vercel data, or an unpatched vulnerability in a public issue. The maintainer will acknowledge a report after reviewing the advisory and will coordinate disclosure when a fix exists.

## Scope

Reports about credential handling, OAuth and PKCE, local data retention, mutation confirmation, and unintended disclosure of Vercel data belong here. Reports about Vercel’s platform or API belong in Vercel’s security program.
